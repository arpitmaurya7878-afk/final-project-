# TaskFlow — Final Web Development Project

Responsive to-do list app built with HTML5, CSS3, and vanilla JavaScript.

## Features
- Add tasks with validation; edit, delete, and mark complete/pending
- Search and filter tasks
- Dynamic total, pending, and completed counters
- Clear completed tasks
- Responsive layout for desktop, tablet, and mobile

## Run locally
Open `index.html` in a modern browser.

## Data behavior
Tasks are stored in a JavaScript array only and reset after refresh.

## GitHub Pages
Push these files to a public GitHub repository. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. Test the published URL.
